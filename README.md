# 递交社团入社申请指南
## 申请流程
### 1.Fork
首先你需要对此仓库进行 **Fork** ,随后 **git clone** 到本地并在你的电脑上按照招新要求编辑它。
### 2.Edit
在你 **git clone** 的项目目录的 **request** 文件夹找到对应当前学年的年份（如2026入学则选择2026目录），并在此目录下创建你的个人简介文件。
### 3.Pull Request
编辑完成后，返回到 **GitHub** ，并向我们的招新申请仓库发送 **Pull Request(拉取请求)** ，将你的个人介绍合并到main分支中。我们的相关负责人会在后台审核这些请求。
****
## 关于介绍文件
### 1.关于个人信息
- 申请人一栏请写自己的 **网名/代号** 等，如果想不到可以直接写自己的 **GitHub用户名** 。
- 联系方式请写自己稳定的
****
## 注意事项
### 1.关于命名
- 考虑到隐私和审计问题，所有自我介绍文件以 **GitHub用户名** 命名，不允许使用真实姓名。
- 并且，Fork后编辑自我介绍的分支统一命名为request。
### 2.关于通知
- 所有入围同学通过 **电子班牌** 和 **PR中的联系方式** 进行通知，并在得到消息后两周内加入社团相关群聊及代码托管平台组织，若无特殊情况，逾期则自动视为放弃资格。
### 3.关于自我介绍的文件格式
- **建议使用Markdown**。PDF或图片格式同样接受。
- 非特殊条件限制不建议使用doc、docx、wps等格式，这可能导致你的入社申请的审核被延缓。
### 4.关于联系方式
- 支持 **QQ、微信、电子邮箱、飞书、电报** 等。
